# DevOps WebApp

A simple static web app used as a target for CI/CD pipeline practice. Demonstrates automated deployment using GitHub Actions.

## Purpose
Used to practice and demonstrate continuous integration and deployment (CI/CD) workflows with GitHub Actions.

## Tech Stack
- HTML
- GitHub Actions (CI/CD)

## CI/CD
The `.github/workflows/ci.yml` pipeline runs on every push and handles automated deployment.

## Run Locally

Just open `index.html` in a browser — no build step needed.
